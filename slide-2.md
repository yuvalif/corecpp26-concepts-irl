# Little Bit on Ceph

* Open Source project started in 2004 (open sourced in 2006)
* ~2M lines of C++ code in ~4.5K C++ source/header files (excluding submodules)
* Has ~1,500 contributors from many organizations
* Software defined, distributed storage used in production for critical infrastructure in thousands of places (e.g. CERN has more than 100 petabytes of data in Ceph)
* Deployed in ~3.7K clusters / ~1.7 exabytes (reported by opt-in telemetry - real usage is much higher)

> Notes: keep it short - the point is "big, old, in production".
> If asked about the numbers:
> * started in 2004 as Sage Weil's PhD research at UC Santa Cruz
> * 1.95M lines in 4,542 C++ files on `main` (October 2026), tests included
> * contributors: "State of Ceph" keynote, which also quotes ~160K commits
> * clusters and exabytes: Ceph telemetry, 2025
> * CERN: CHEP 2024 paper, "overall capacity exceeding 100 PB"
